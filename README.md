# AF問答帳（自分専用アプリ版）セットアップ手順

このフォルダの中身を公開すると、claude.aiの外で動く、マイクも使える本物のウェブアプリになります。
プログラミングの知識がなくても、クリックだけで進められる手順にしてあります。

全体の流れは3つだけです。

1. GitHubに、このフォルダの中身を置く
2. Vercel（ホスティングサービス）にGitHubをつなげて公開する
3. AnthropicのAPIキーを取得して、Vercelに設定する

---

## 1. GitHubにアップロードする

1. https://github.com にログインする
2. 右上の「+」→「New repository」を選ぶ
3. リポジトリ名を決める（例：`af-mondouchou`）。公開・非公開はどちらでもよい（迷ったら「Private」）
4. 「Create repository」を押す
5. 作られた画面の中の「uploading an existing file」というリンクを押す
6. このフォルダの中身（`index.html`、`notes.json`、`package.json`、`.env.example`、`api`フォルダ）を、まとめてドラッグ＆ドロップする
7. 一番下の「Commit changes」を押す

---

## 2. Vercelで公開する

1. https://vercel.com にアクセスし、「Continue with GitHub」でサインアップ（GitHubのアカウントでそのままログインできる）
2. ダッシュボードで「Add New...」→「Project」
3. 先ほど作ったリポジトリ（例：`af-mondouchou`）を選んで「Import」
4. 設定画面はそのままで構わない（Framework Presetは自動で「Other」になります）
5. まだ「Deploy」は押さず、次の3.でAPIキーを設定してから押してください

---

## 3. AnthropicのAPIキーを取得して設定する

APIキーとは、「あなたの契約でAIを使う」ための合言葉のようなものです。これがないと、AIが答えを作れません。

1. https://console.anthropic.com にアクセスし、アカウントを作る（またはログイン）
2. 支払い方法（クレジットカード）を登録する（使った分だけ課金される従量制です）
3. 「使いすぎ防止」のために、画面の中の「Limits（利用上限）」で、月の上限金額を設定しておくことを強くおすすめします（例：月1,000円など）
4. 「API Keys」のページで「Create Key」を押し、表示されたキー（`sk-ant-...` という文字列）をコピーする
   - このキーは一度しか表示されません。必ずどこかに控えておいてください
5. Vercelの画面（2.の続き）に戻り、「Environment Variables」という欄に、次のように入力する
   - Name: `ANTHROPIC_API_KEY`
   - Value: コピーしたキー
6. 「Add」を押してから、「Deploy」を押す

数十秒〜数分待つと、`https://af-mondouchou-〇〇.vercel.app` のようなURLが発行されます。これがこやたさん専用のアプリのアドレスです。

---

## 動作確認

1. 発行されたURLをスマホやパソコンのブラウザで開く
2. 何か質問を送ってみる（例：「CCr 20の患者にDOACは使える？」）→ 答えが返ってくるか
3. 🎤ボタンを押す → 今度は「マイクを許可しますか」という、ちゃんとしたポップアップが出るはず。許可すると声で入力できる
4. 🔈ボタンで読み上げも確認する

---

## 知っておいてほしいこと

- **このURLを知っている人は誰でも使えます。** そのたびにこやたさんのAPI利用料がかかります。人に送るときは注意してください。他の人に見せたくない場合は、今のところパスワードなどの仕組みは入っていないので、URLを教えないでおくのが一番簡単な対策です（本格的に人に使わせるなら、後でログイン機能を足せます）。
- **使う分だけ課金されます。** 1回の質問・回答で、だいたい数円〜十数円くらいが目安です（ノートの分量やAIの種類によって変わります）。心配なら、Anthropicの画面で上限額を必ず設定してください。
- **`notes.json` を書き換えれば、ノートの中身を更新できます。** Obsidianのノートを直したら、この `notes.json` も直して、GitHubに再アップロードすると、Vercelが自動で新しい内容に更新してくれます（毎回この手順は不要で、GitHub上のファイルを直接編集する方法もあります）。
- **費用を抑えたい場合：** `api/chat.js` の中の `model: 'claude-sonnet-5'` の部分を `'claude-haiku-4-5-20251001'` に変えると、費用は安くなりますが、答えの精度は少し落ちる可能性があります。まずは今のままで試してみることをおすすめします。

---

## わからなくなったら

この手順のどこで詰まっても、その画面のスクリーンショットを見せてもらえれば、続きを一緒に進められます。
